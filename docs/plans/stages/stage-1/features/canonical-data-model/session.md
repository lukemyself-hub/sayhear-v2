### run/attempt 生命周期讨论

已沿主路线失败、备用成功及显式重试解释 run 与 attempt 的关系。候选 run 状态为 created、running、succeeded、failed、interrupted；正常生成且保存成功才算整体成功，结束原因另存。Luke 明确认可首段前主动停止也归 interrupted，不建空回答、不 fallback，已记录 ADR 0005；不把该回应扩大为完整状态机已收口。

下一段解释的建议边界：attempt 的成功仅表示 Provider 正常完成本次生成，run 的成功还要求应用完成必要保存。因此最终保存失败可以出现 Provider attempt 成功而 run 失败，失败位置记为持久化，不自动调用另一个 Provider 重生成。状态字段与命名仍随完整方案审阅；若数据库不可写，不能声称失败终态已可靠落库，需在后续恢复契约处理。当前没有新的理解判断证据。

理解观察更新：Luke 指出，仅凭刷新后只有部分回答不能判断 Provider 未完成，也可能是服务端写入失败；会先检查 attempt，再检查其引用的 run。这是本场景中能区分生成与持久化的具体证据，不扩展为已掌握整个生命周期。后续校准是：两类记录都可能未及时持久化，缺少成功终态不等于 Provider 失败；已有 run 的保存错误也应一并检查，不要求固定查询顺序。

下一建议：超过可信执行期限仍无终态的 run，按既有 SPEC 恢复为 interrupted，并记录“执行失联、未取得最终状态”一类原因；只保留已落库内容，不自动重新调用 Provider。已有明确 attempt 终态保持不变；缺少可靠结束证据的 Provider 结果记 unknown，而非推定 failed、succeeded 或停止计费。unknown 的具体字段布局尚未确定，不等同于新增一个永远进行中的运行状态。期限必须结合应用总上限与收尾余量，不能仅凭刷新或短暂没有内容就判死；与正常收尾竞争时的原子条件更新交给 M4 细化。

- 消息内容采用 AI SDK parts，存 jsonb，不提前设计自有 parts 或转换层。未来实际不兼容时，再选择保留旧格式并读取时转换或迁移。格式版本标签的具体列尚未确定。
- 消息生成状态为 generating / complete / interrupted，与 deleted_at 分开。
- 阶段 1 不接外部观测工具，继续按 ADR 0005 将运行记录存于 SayHear。未来可仅对新运行接入，无须强制迁移历史；历史导入能力、费用与耗时届时按目标平台评估。
- 阶段 1 关闭 reasoning，不保存异常返回的思考原文；将来开启 reasoning 时需要保存 Provider 实际提供的推理内容并支持检查。工具调用和 reasoning 是独立能力，不互为启用前提。

## 待定、依赖与冲突

- 首次出现事件是正文、可见推理还是其他内容；生成中继续发送的排队功能是否纳入阶段 1、逐条还是合并执行、删除取消及失败后续策略均未定。讨论存储兼容性不等于授权实现队列。
- 不得用聊天展示顺序推断某次 run 的输入。排队消息不能因已落库而自动混入当前 run 后续工具步骤。
- 行粒度已核对并保持 ADR 0010 的“一个 run 至多一条 assistant 消息”；不得因 SDK 便利自行改变来源与数量契约。
- 删除清空及并发保护已获 Luke 确认，见 ADR 0015：parts 为 JSON 数组且不允许 SQL NULL，删除时原子清为 [] 并设置 deleted_at；数据库约束 deleted_at 非空时 parts 必须为 []。所有流式与最终保存须在原子更新中检查 deleted_at 为空，已删除则跳过内容更新，不得清除删除标记。其他含内容的消息列也须清空。生成中删除是否同时停止运行仍未定。
- 阶段 1 不设独立 system 聊天行，实际指令经请求快照保存、检索和展示，已由 Luke 确认并记录 ADR 0016。此前 role=system 合成行候选已撤回，未曾接受。ADR 0010 已同步不设独立 system 行及快照合并布局；Issue #1 的系统消息措辞仍待获发布授权后修订。SDK 参数按锁定版本核实。
- Issue #1 要求合成工具记录；采用 parts 后需明确表达方式与测试，不能继续机械使用 tool_call/tool_result 独立行草案。需变更已发布 SPEC 时另获授权。
- 附件表和对象存储只是此前建议，不作为已接受结构。阶段 1 不因此增加多模态实现。
- ADR 0004 的 system/instructions、request.messages opt-in 表述与所查 v7 不一致，相关源码证据见 AI SDK 报告；修订时明确验证版本，不把历史实验改写为已测新版行为。
- 外部观测未来接入涉及 ADR 0005 数据外送与清理边界重评；不因平台支持导入就推定应迁移历史。
