# 待整合的需求核对记录

本文件记录从仓库共识提取的约束，不是技术选型结论。

## 年底交付约束

- 先完成基础对话与 canonical 数据，再引入人格、基础记忆和 Reflection。
- 文本 Agent 可在 Vercel Web 日常使用，线上独立于开发电脑。
- 模型调用、流式输出、工具调用、停止和失败处理、Provider 替换均须涵盖。
- 提供运行详情，能展开实际模型输入、历史选择、工具调用与失败位置。
- 测试数据充足且关系清晰，可重复装载恢复，与真实用户数据库隔离。
- 用户自述、AI 推断与随时间更新的画像可区分，保留依据。
- 初期访问控制、内容查看与清理、数据归属支持未来多用户。
- 不把完整纠正遗忘、日记、Open Loop、实时语音或完整多用户塞入年底承诺。

## 学习和协作约束

- 每周约 10 小时包含讨论、阅读、体验、讲解和笔记，Agent 后台工时另算。
- 每阶段覆盖完整机制，阶段启动再进行专项调研与具体设计。
- Luke 能结合真实运行解释结构、流程与取舍才构成理解证据。
- 不用课时、背诵、考试或笔记完成度代表掌握。
- 采用成熟实践，只有资料无法解决而且影响决策的未知才安排有限验证。
- 关键架构和范围变更实施前与 Luke 达成共识。本次推荐保持 Proposed。
