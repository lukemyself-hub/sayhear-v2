# 审计与执行记录

- `roadmap/`：跨阶段路线制定、评审、来源检查与历史执行轨迹。
- `stages/stage-N/`：阶段专属任务清单、验证与操作记录。
- `tooling/<tool-slug>/`：技能及 Agent 工具维护记录。
- 后续功能审计使用 `stages/stage-N/features/<feature-slug>/`，并行任务各写独立文件。

这些材料用于追溯过程，不作为最新产品决定。产品背景读 `CONTEXT.md`，决定读 ADR，完整 SPEC 读 GitHub Issue，进度读对应阶段的 session。

旧记录中的完成或未完成状态描述当时的过程，不能据此覆盖后续阶段记录。验证脚本的运行命令须从仓库根目录执行。
