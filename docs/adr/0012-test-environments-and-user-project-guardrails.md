# 三层测试环境与用户库的三道护栏

沿用 [ADR 0001](0001-database-and-managed-auth.md) 的两个 Supabase Free 项目，增加本地 Supabase 栈，兼顾可重复自动测试与真实托管环境验证。Luke 于 2026-10-23 确认三层分工、工具安装及下列三道护栏。调研见 [测试环境隔离证据](../plans/stages/stage-1/features/identity-data-ownership/evidence/test-environment-isolation-evidence.md)；本 ADR 优先于证据报告中的早期建议。尚未安装工具、创建项目或运行验证。

## 环境分工

- 本地：OrbStack 运行 Supabase 栈，Supabase CLI 管理；承担自动测试、RLS 越权验证、Auth 生命周期和合成数据装载。Luke 已同意安装两项工具，进入实施时执行。
- 云端测试项目：迁移演练、Vercel Preview 冒烟验证和恢复演练，只含合成数据。共享该项目的验证须隔离数据或串行执行。
- 用户项目：真实聊天与经授权的真实使用检查；Vercel Production 指向这里。自动测试与合成数据装载不得接触它。

## 三道护栏

1. **凭据隔离**：日常开发和测试不在开发机配置文件、测试进程或测试 CI 中保存、注入用户库凭据。应用用户库凭据仅配置于 Vercel Production；本地开发使用本地栈，Preview 使用测试项目。测试装载工具只读取测试专用变量，缺失即退出，不回退到应用变量。用户库迁移所需管理凭据仅在单独授权的操作中临时提供，实施时核实 CLI 的凭据保存行为与清理方式；备份进程的凭据另行设计，不与测试共享。
2. **写入前核验目标身份**：从连接 URL 得到项目 ref，与独立配置的期望 ref 比对；再以只读探测读取库内环境身份记录（sentinel），核对 ref 与环境类型。普通测试只接受本地目标，显式启用的远端验证只接受已登记测试项目；均拒绝 `user`。缺失、读取失败、信号矛盾一律中止（fail closed）。用户库身份记录在受控初始化时登记，应用用户与测试身份不得改写，测试装载不得创建或覆盖它。新式 API key 不能靠解码识别项目；使用所配 URL/key 完成只读探测，失败不得进入写入路径。不以库名、环境变量文件名或单一加载器规则证明隔离。
3. **迁移操作隔离**：迁移统一经包装脚本，执行前核对 CLI 实际关联项目与操作目标。顺序为本地重放、云端测试演练、独立授权后用户库执行。用户库推送需显式选择用户项目、先 dry-run 审阅，再由 Luke 确认执行；测试流程不包含用户库推送或重置。dry-run 仅预览待执行迁移，不能替代执行验证或授权。

## 取舍与限制

相较全部测试使用云端项目，多维护一套本地栈，但可快速重置并减少共享测试数据冲突。相较只靠配置自觉或 Next.js 跳过 `.env.local`，三道护栏增加初始化和检查流程，以降低配置误贴及 CLI 关联状态残留导致误写的风险。

护栏防范操作失误，不承诺抵御持有用户库管理员权限的人蓄意改写全部身份信号。身份记录的初始化、权限及缺失时中止必须在实施期验证；破坏性误配测试只能使用隔离的合成环境，不连接真实用户库。本地与托管环境仍有签名密钥、网络及服务配置差异，需云端测试项目验证。工具版本、端口并行方案及实际资源占用在实施时核实。

## 重评条件

需要并行 Preview 独立数据库、远端自动测试频率上升、本地与托管差异造成遗漏，或备份运维要求改变凭据边界时重评。
