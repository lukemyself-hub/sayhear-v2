# Triage Labels

技能用五个标准 triage 角色描述工作流。本文件把这些角色映射到本仓库 issue tracker 实际使用的 label 字符串。

| mattpocock/skills 中的角色 | 本仓库的 label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估这个 Issue |
| `needs-info` | `needs-info` | 等待报告方补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以交给 AFK agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不做处理 |

技能提到某个角色时（例如「apply the AFK-ready triage label」），使用表中右列对应的 label 字符串。

右列可随时改成本仓库实际使用的词表。仓库当前的 label 里 `wontfix` 已存在（GitHub 默认），其余四个尚未创建，需要时由技能自行创建。
