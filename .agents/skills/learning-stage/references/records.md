# 接续与学习记录

## 接续文件

按阶段和功能归类，接续文件为 `docs/plans/stages/stage-N/features/<feature>/session.md`；既有同职能文件先复用，收尾按 SPEC 交接指南迁移并更新指针。主 Agent 串行维护，worker 写独立证据。注明更新时间与来源，恢复时核实状态。

保留以下字段，空项省略，细节用链接：

- 目标：阶段计划与任务、体验目标与完成条件、本次目标、学后能解释或判断的机制、授权来源与边界。
- 状态：当前环节、下一动作、产物与证据、决定与 ADR、推荐、待决定项、阻塞、未知及影响。
- 计划：按依赖排列调研、讨论、决策、学习、SPEC；Luke 待决问题与推荐；活跃委派标识、结果路径、接续方式。
- 学习及注意事项：笔记链接、理解证据、未确认与回访点、同步状态及待同步路径、文档冲突、过期风险、并行改动。
- 交接：SPEC 草稿状态或 Issue 链接、阻塞性未决项与非阻塞待验证项、文档目录索引、PR 与合入回执链接、构建会话先读什么及先做什么。

按入口规定的节点及时更新，不等用户宣布结束。摘要简短；暂停或上下文将满时优先保存下一步和未解事项。

## 学习笔记

目录以 `CONTEXT.md` 为准，当前为 `/Users/lukemyself/Documents/学习/AI/Agent Harness`。写前核对 `study-notebook` 链接目标和已有分类，只读相关主题与理解记录；内容不进产品仓库。

复用已有结构，空目录按需创建：

- `topics/<topic>.md`：机制、适用条件、取舍、案例、来源。
- `learning-records/<date>-<session-id>-<topic>.md`：目标、实际理解表现、缺口、回访。
- `index.md`：主题与阶段链接，阶段末整理。

记录阶段、日期、关联提交及是否合入；无实现则标设计讨论、尚无代码，不以 HEAD 暗示落地。仅摘要必要技术讨论，不复制全聊天或私人内容。区分已讲、具体理解表现、需提示、未确认，不自动标掌握。

并行会话用独立标识写记录。更新共享主题与索引前核对其他写入者，由主 Agent 串行整合；无法协调则保留独立记录并标待整理。

符号链接不扩大写权限。权限不足走正常授权机制；仍不可写则在接续文件记待同步摘要与目标路径，恢复后核对同步。不得伪称已同步或把产品仓库作为永久笔记目录。
