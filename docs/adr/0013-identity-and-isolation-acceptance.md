# 身份与隔离验收分别覆盖应用、数据库、环境护栏和部署链路

Luke 于 2026-10-23 接受四组验收方案，用以验证 [ADR 0009](0009-server-data-access-and-rls.md)、[0010](0010-minimal-data-contract-and-owner.md)、[0011](0011-stage-1-login-lifecycle.md) 和 [0012](0012-test-environments-and-user-project-guardrails.md)。应用入口拒绝越权不能证明数据库兜底有效，因此必须独立验证各层。本文记录验收契约，不代表已实现或测试通过。

## 四组验收

| 层面 | 场景 | 必须观察的结果 |
| --- | --- | --- |
| 应用入口 | 无 cookie、伪造 cookie、登出后重放旧 cookie；提交伪造 owner | 私人数据请求被拒绝；owner 由已验证的服务端身份取得，客户端不能指定归属；失败请求不产生业务写入 |
| 数据库 | 使用合成主体 A 的用户令牌直接请求 Data API，读写 B 的数据；以 A 的记录引用 B 的父记录 | 读取不泄漏，写入不生效，跨 owner 引用被约束拒绝；不得使用绕过 RLS 的管理身份代替 A 执行被测操作 |
| 环境护栏 | 混配 URL、key、期望 ref 与环境身份；身份记录缺失或读取失败；模拟 user 目标 | 业务写入、合成装载、迁移执行前停止；检查目标数据没有改变，不能仅凭报错认定安全 |
| 部署链路 | 云端测试项目迁移，Preview 登录、续期、读写、登出；恢复演练沿用 ADR 0001/0012 | 托管环境满足契约，续期 cookie 正确回写；恢复结果有单独证据 |

## 登录生命周期的具体检查

- 关闭公开注册后，预先开通且确认邮箱的合成账号可用密码登录；错误密码失败，未开通账号不能自行注册。真实账号的控制台开通仅在单独授权后操作。
- 登录后可读写自己的合成记录；A/B 交替访问不能串用身份或缓存。
- 在隔离环境控制令牌有效期，使 access token 到期但 refresh token 仍有效：请求经真实续期路径完成，响应回写 cookie，浏览器带新 cookie 的下一次请求仍可访问自己的数据。不能只 mock 刷新函数后声称通过。
- 无法续期时，私人数据请求拒绝并回到可重新登录的状态；错误响应不得泄露令牌或私人内容。
- 登出前保留一份完整 cookie；登出成功后，在独立客户端重放它，分别请求读取和写入接口，必须立即被拒绝且无业务写入；同时确认原浏览器已退出。重新登录取得的新会话可正常使用。
- 长回复前原令牌不足以覆盖预算时，在输出前完成续期；验证响应头带新 cookie、跨过原令牌到期时刻后 checkpoint 仍成功、下一次浏览器请求正常。续期失败或有效期仍不足时不得启动生成。
- 在一个合成会话里启动回复，另一个客户端登出同一会话：登出后的新读写请求立即拒绝；原回复允许在原预算内完成并保存，不将其继续运行记为撤销失败。此边界由 Luke 于 2026-10-23 确认。
- 登出重放的结论以实际行为为准，不以调用了 `getUser()` 等函数作为通过依据。锁定版本是否检查会话撤销必须核实；若不能兑现立即拒绝，需要回到 ADR 0011 补足会话存在性检查，不得降低已确认的验收标准。

## 执行边界与证据

自动测试仅使用本地或明确允许的云端测试目标和合成数据。模拟 user 环境必须使用隔离合成目标，绝不把破坏性测试指向真实用户库。测试身份不得改写真实环境身份记录；初始化和模拟夹具的权限与执行路径分离。

每项证据记录环境、版本、前提、动作、预期和实际结果，并核对写入前后状态。cookie、密码和令牌不得进入仓库、日志或截图。未运行、失败或被环境阻塞分别记录。应用、RLS、环境护栏和托管验证缺一项，均不得用其他层通过替代。
